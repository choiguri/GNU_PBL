# 🛡️ Project Battle Line (PBL)
**경상국립대학교 컴퓨터과학과 3학년 2학기 PBL(Problem Based Learning) 과목 프로젝트**

> **🏆 캡스톤 디자인 경진대회 최우수상 수상** > **🎮 Unreal Engine 5 기반의 3인칭 보스 레이드(TPS) 액션 게임**

---

### 👥 Team Information
- **팀 구성:** 이민수, 박지우, 최태영, 안건호, 변하연 (5인)
- **개발 기간:** 2024.09 ~ 2024.12

### 🛠️ Tech Stack
- **Engine:** Unreal Engine 5
- **Language:** C++, Blueprint
- **Network:** Listen Server
- **VCS:** GitHub

### 🚀 Key Features
- **Boss Raid System:** Behavior Tree를 활용한 정교한 보스 AI 패턴(근거리/원거리/광역기) 구현
- **TPS Combat:** 투사체 기반의 사격 시스템과 회피, 타격 로직 구축
- **Optimization:** 대용량 에셋 최적화 및 안정적인 프레임 확보를 위한 코드 최적화
- **Interactive UI:** 실시간 보스 체력 바 및 플레이어 스테이터스 위젯 시스템
